# Installation

This beta is for Digitakt II using the exact official OS 1.16 source file. Back up important projects, presets, and samples first.

1. Download the Windows builder from the v0.1.0-beta release.
2. Obtain official Digitakt II OS 1.16 from [Elektron Support & Downloads](https://elektron.se/support-downloads).
3. Run DT2-DejaVu-Builder.exe.
4. Select the official OS 1.16 .syx, choose an output location, and click **Build Déjà Vu**.
5. Wait for the success message. The verified output SHA-256 is d9fe67b3778ce5d31aaaa807e6e43ac1929d0f36a10c393adc0a8c590c547835.
6. Connect Digitakt II directly by USB and open Elektron Transfer.
7. Select Digitakt II for MIDI IN and MIDI OUT, then drop the generated .syx on the **DROP** page.
8. Follow the prompts and confirm the update on the device.
9. Keep power and USB connected until installation finishes and the instrument reboots.

Official reference: [Elektron — How to update your device](https://support.elektron.se/support/solutions/articles/43000662890-how-to-update-your-device).

The builder does not connect to Digitakt II, invoke Elektron Transfer, or install firmware.
