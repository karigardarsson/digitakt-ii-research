## Important omissions and limitations

- The quantizer condition checks numeric destination25, not an explicit SAMPLE machine-type guard. That slot is also used by other machine paths. The guide documents the established SAMPLE use without inventing Plaits/MIDI behavior or falsely proving those paths impossible.
- core/params/module.toml explicitly leaves owner-enumeration loops at the stock count. A README statement that every new knob is an LFO destination is therefore insufficient. No Plaits TIMBRE-LFO recipe is published by this guide.
- Generic LFO page-cycling gestures, custom randomize shortcuts, exact root-transposition recipes and complete save/reload instructions are omitted where this bounded audit did not establish their complete current paths.
- Earlier Kári hardware observations establish musical use and preceding UI/Zoom behavior, not every table entry/control case on exact426dd1be. All detailed source semantics are labeled SOURCE-PROVEN rather than being promoted to hardware proof.

## Final prose verification

Guide tables cross-checked against current manifests, formatter tables and DV kernel/maps. Examples use one SAMPLE TUNE LFO, supported WAVE selection, documented MODE length and SPH mutation; no claim of absolute C-major playback, a new root control, arbitrary-destination pitch quantization, transport reset, saved random motif or a click fix. No Syntakt control instructions reused. Firmware/release assets remain unchanged; guide publication was subsequently authorized during v0.3.0 release polish.
