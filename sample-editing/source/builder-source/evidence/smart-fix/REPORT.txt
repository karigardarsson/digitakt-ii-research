On both successful analysis and failure, smart_grid calls smart_notice.
smart_make_text uses native401AE1C4; it creates a shared notification View,
represented by {object,control}. Native4011B22A displays/copies that owner.

local owner unreleased. The correct call is &message.control.

and uses the corrected existing error notification. No forced count, new cut
algorithm, generic event suppression or notification disabling is introduced.
