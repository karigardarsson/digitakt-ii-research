# Machine types

Framework for modules that add machine types to the Digitakt II and the Digitone II. It has no effect on its own; it is
selected automatically by modules such as XSLICE and PLUCK.

On the Digitone II a machine can also have **its own parameter pages** (with `core/params`): its own SYN pages with its
own page names, knob names, ranges and defaults, instead of a clone of FM TONE's pages.
