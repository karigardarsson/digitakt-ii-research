## Earlier Déjà Vu / Zoom editions

# Digitakt II Déjà Vu + ONESHOT Zoom

An unofficial Digitakt II OS 1.17 and OS 1.16 modification that adds two random-loop LFO waveforms:

- **DV-F** (WAVE 7): a free-running random loop.
- **DV-T** (WAVE 8): a random loop whose read position resets when the track triggers. Retriggering does not erase the stored loop.

DV-F and DV-T are available on all three LFOs. Stock WAVE 0–6 remain on their original firmware paths.

## Controls

MODE selects a loop length of 2, 4, 8, 16, or 32 steps.

SPH controls the random loop:

- 0: generate a new random value when each step is visited.
- 64: lock the stored values and their order.
- 127: retain the stored values while reordering them.
- Intermediate values blend probabilistically toward the corresponding endpoint behavior.

Existing SPD, MULT, FADE, DEP, and DEST processing remains on the stock paths.

## ONESHOT Zoom

The OS 1.17 combined edition adds real waveform detail to the ONESHOT SRC waveform page. Press encoder C to cycle 1x, 2x, 3.75x, and 1x. Turn C to pan while zoomed. Zoom depends on Déjà Vu's runtime allocation and is therefore not offered as a standalone edition.

## Hardware status

The exact OS 1.16 and OS 1.17 V5.1 outputs have both been generated by the Windows builder and tested on a physical Digitakt II. For OS 1.17, initial testing confirmed normal boot, DV-F modulation, DV-T modulation and retrigger, and normal operation with no problems observed. This is initial hardware validation, not exhaustive long-term regression. Across the two tested builds:

- Normal boot completed.
- DV-F and DV-T appeared on the LFO pages.
- Both custom waveforms produced modulation.
- DV-T repeating and retrigger behavior was observed.
- Stock LFO waveforms remained functional.

Offline verification also covers exact package identity, six-section decode, HMAC/checksums, stock WAVE 0–6 differential behavior, native ColdFire routing, and Sound-object conversion.

The following areas remain incomplete or limited:

- Broad MIDI, sequencer, transport, and synchronization regression.
- Real Sound/Pattern/Project save, reload, and power-cycle persistence.
- Long-duration stability across a wider set of projects.
- Compatibility with every setup, project, or future OS version.

## Repository contents

- windows-builder/: Windows GUI builder source, tests, frozen V5.1 patch data, and pinned MIT-licensed container tooling.
- src/dv/: deterministic host model and native phase-input adapter.
- coldfire/: ColdFire DV, routing, trampoline, and startup-allocation source.
- tests/: standard-library host tests.
- research/: byte-backed findings and evidence reports.
- tools/midisniff.py: passive SysEx capture and envelope decoder; it does not transmit.

No official Elektron firmware, extracted firmware section, emulator snapshot, generated firmware, sample library, or credential is stored in this repository.
